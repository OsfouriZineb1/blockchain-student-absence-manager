# Decentralized Student Absence Management System (Blockchain)

## Project Overview
This repository contains the architecture and source code for a secure, blockchain-based academic absence management platform. Developed as a graduation project (PFE), this system solves the critical issue of academic data vulnerability by replacing traditional, centralized attendance databases with a decentralized ledger.

By utilizing blockchain technology, the platform ensures that all student attendance records and absence logs are immutable, transparent, and mathematically cryptographically secured against unauthorized modifications or retroactive tampering.

## Core Architecture & Features

1.  **Immutable Ledger Storage:** Student absences are recorded directly onto the blockchain, creating a permanent, tamper-proof historical record of academic attendance.
2.  **Smart Contract Logic:** Automated smart contracts handle the business logic of verifying, logging, and retrieving absence data, ensuring that only authorized academic personnel can append records.
3.  **Decentralized Verification:** Eliminates single points of failure inherent in standard relational databases, guaranteeing the highest level of data integrity for institutional records.
4.  **Admin Interface:** A streamlined frontend application that allows professors and administrators to interact seamlessly with the underlying blockchain infrastructure via Web3 integrations.
